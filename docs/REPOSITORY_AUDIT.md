# Repository Feature Audit

Date: 2026-09-11. Branch: `codex/offline-frame-generation`.

Scope: all first-party Swift source files, tests, package manifest/resolution, README, and packaging script, grouped by their owning feature. Dependency internals were inspected where relevant to the fx-upscale integration, not exhaustively audited. This is a fix-and-validate pass, not a claim that every advertised feature is complete.

## Open Findings, In Priority Order

1. **P1: Corrupt SwiftData store still prevents launch.** `Sources/MacWallpaperEngineApp/App/MacWallpaperEngineApp.swift:19` calls `fatalError` if the container cannot open. Empty-store snapshot recovery is fixed, but a genuinely corrupt store needs an explicit non-destructive recovery screen and backup/migration workflow. Do not recommend deleting the user's database.
2. **P1: Desktop edit mode is not a functioning widget drag editor.** `Sources/MacWallpaperEngineApp/Rendering/WallpaperCoordinator.swift:441` changes interaction/placeholder state; there are no corresponding desktop widget drag handlers. The toggle provides an exit, but the advertised workflow is incomplete. Implement hit testing, dragging and persistence, or remove the interaction-taking toggle until supported.
3. **P2: Hardware and weather widgets contain placeholder data.** `Sources/MacWallpaperEngineApp/Widgets/WidgetRuntime.swift:139` returns constant CPU text; memory shows capacity rather than usage. The weather module at line 159 displays an offline label without a provider/setup flow. Refresh throttling is fixed, but these must not be marketed as real-time meters/forecasts.
4. **P2: Playlist crossfade can replay the next clip's opening segment.** `Sources/MacWallpaperEngineApp/Rendering/PlaylistCompositionFactory.swift:29` blends the beginning of the next clip into the outgoing one, while the following queued item starts at zero. Different resolutions/transforms also need alignment tests. Use a continuous timeline or carry transition offsets into subsequent items; test actual frame continuity. Zero crossfade is the existing escape hatch.
5. **P2: Preview is a poster, not live playback.** `Sources/MacWallpaperEngineApp/UI/Editor/ContentView.swift` (`LivePreviewPane`) renders an NSImage. Canvas resolution controls affect presentation, not the decoded file's pixel dimensions. README and tooltip now say so; preview naming and full live editing need a separate implementation decision.
6. **P2: Export quality/backend reporting is incomplete.** `Sources/MacWallpaperEngineApp/ImportExport/SmoothVideoExporter.swift:223` falls back from MetalFX to scaling, and optical flow can fall back to blending. There is no user-visible backend report. Constant-rate sampling does not preserve arbitrary VFR timing, and the 8-bit pipeline does not preserve HDR. Optical flow is recomputed for each intermediate frame instead of cached per source pair. Add diagnostics, quality fixtures, and pair caching before claiming DLSS-like results.
7. **P2: Import/storage recovery needs more work.** Import validation after copying can leave an unused managed file when metadata validation fails. Reimport uses managed-path identity, not content deduplication for renamed external files. Missing-file errors are visible, but there is no relink action or disk-usage manager. Finder access provides a deletion path, but deleting an assigned file still requires clearing/removing its library record.
8. **P3: Remaining verification gaps.** Dock/file-drop delivery, menu bar reopening after closing the library, live multi-display switching, relaunch with real assigned playback, login registration on a deployed bundle, Gatekeeper on another Mac, accessibility of the custom range slider, and long-running 1080p/4K energy measurements have not been completed. No performance percentage is claimed.

## Cleanup Decisions

- Removed unused `TrimEditorSection` and `TimeValueField`, duplicate editor fingerprint reconciliation, the duplicate 60-second UI timer, unused smooth-export busy state, and an unused coordinator logger.
- Kept `AppSettingsRecord` in the SwiftData schema: removing a historical model without a migration is not safe cleanup.
- Kept decoding/rendering for legacy overlays; Settings offers a disable action when legacy widgets are active.
- Retained fx-upscale rather than reintroducing a private upscaler. MetalFX and optical flow are different operations; fx-upscale is not DLSS frame generation.

## API References Checked

Apple explicitly requires workspace notifications to be observed through the workspace notification center: [screensDidSleepNotification](https://developer.apple.com/documentation/appkit/nsworkspace/screensdidsleepnotification).

Apple recommends async image generation for Swift callers: [AVAssetImageGenerator image generation](https://developer.apple.com/documentation/avfoundation/avassetimagegenerator/generatecgimageasynchronously(for:completionhandler:)).

The deployment target remains macOS 14. Public APIs compatible with that target are retained rather than unconditionally adopting macOS 26-only replacements.
